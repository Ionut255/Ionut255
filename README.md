## 🚀 Featured AI Projects

### 🛡️ [Smart Spam Detector](https://github.com/Ionut255/AI-spam-detector)

An explainable SMS spam classifier built with **Python, scikit-learn, TF-IDF, Logistic Regression, and Streamlit**.

- Classifies English SMS messages as **SPAM** or **NOT SPAM**, with prediction scores and influential words.
- Compared **Logistic Regression** and **Multinomial Naive Bayes** on the same held-out test set.
- Achieved **97.9% accuracy** and **91.6% F1-score** with Logistic Regression on the project's test split.
- Includes automated tests with **pytest / GitHub Actions** and a deployed web interface.

**[💻 Source Code](https://github.com/Ionut255/AI-spam-detector) · [🌐 Live Demo](https://ai-spam-detector-df3arof2loyabguty9ipr2.streamlit.app/)**

### 📄 [DocuMind AI — Chat with Your Documents](https://github.com/Ionut255/documind-ai)

A PDF question-answering app using **Retrieval-Augmented Generation (RAG)**.

- Extracts text from PDFs, splits it into chunks, and generates embeddings with **Sentence Transformers**.
- Uses **ChromaDB** for semantic search and **Google Gemini** to answer questions using retrieved context.
- Supports follow-up questions, conversation history, and **page-based source references**.
- Built with **Python, PyPDF, Streamlit, ChromaDB, and Google Gemini**.

**[💻 Source Code](https://github.com/Ionut255/documind-ai) · [🌐 Live Demo](https://documind-ai-jqxjfypyn38yxy9n8vyuko.streamlit.app/)**

### 🧠 [VisionAI — AI Image Recognition](https://github.com/Ionut255/ai-image-recognition)

A computer-vision web app that classifies images using a **pretrained Vision Transformer (ViT)**.

- Accepts JPG, JPEG, and PNG images and displays the **top 5 predictions** with confidence scores.
- Integrates **PyTorch** and **Hugging Face Transformers** for model inference.
- Includes interactive visualizations, image information, and downloadable **JSON results**.
- Uses the pretrained **`google/vit-base-patch16-224`** model; no custom fine-tuning is claimed.

**[💻 Source Code](https://github.com/Ionut255/ai-image-recognition) · [🌐 Live Demo](https://ai-image-recognition-3cj3rvwyawptnrjfnfrmyr.streamlit.app/)**
